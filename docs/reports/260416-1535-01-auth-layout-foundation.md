# 인증 레이아웃 사전 준비

## 작업 배경

- 로그인 페이지를 실제 기능 구현 전에 모바일 중심 인증 화면으로 정리할 필요가 있었습니다.
- 기존 `/login`은 플레이스홀더 한 장으로만 존재했고, 공통 입력 UI와 인증 레이아웃 토큰이 없었습니다.

## 이번에 반영한 내용

- `src/app/(auth)/layout.tsx`를 추가해 인증 라우트가 공통 배경과 중앙 정렬 레이아웃을 공유하도록 정리했습니다.
- `/login` 엔트리를 route group 아래로 이동해 URL은 유지하면서 인증 화면 전용 레이아웃을 사용할 수 있게 했습니다.
- `src/shared/ui/input.tsx`를 추가해 로그인 폼에서 재사용할 입력 프리미티브를 준비했습니다.
- `src/widgets/auth/auth-screen-shell.tsx`를 추가해 인증 화면 헤더와 카드 레이아웃을 분리했습니다.
- `src/app/globals.css`에서 인증용 semantic token, 그림자, 반경, 타이포그래피 기반을 정리했습니다.
- 루트 폰트를 한국어 본문에 맞는 sans로 바꾸고, 브랜드 강조용 display font를 별도 변수로 분리했습니다.

## 후속 작업

- `docs/todo/auth-api-integration.md` 기준으로 실제 제출 액션과 OAuth 버튼 동작을 연결합니다.
- 회원가입, 비밀번호 찾기 경로가 확정되면 현재 텍스트 자리표시자를 실제 라우트 링크로 교체합니다.
