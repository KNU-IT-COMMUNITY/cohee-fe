- 진행 시점: Figma Dev Mode 접근 권한과 유효한 노드 링크가 확보된 직후

## 목표

- Figma에 정리된 UI 이미지 전부를 화면 단위로 분석합니다.
- 반복되는 시각 패턴과 인터랙션 패턴을 기준으로 공통 컴포넌트 후보를 식별합니다.
- 후보를 `src/shared/ui`, `src/widgets`, 추후 `src/entities` 중 어디에 둘지 결정합니다.

## 요구사항

- 각 이미지가 속한 프레임 또는 노드 링크를 정확히 식별할 수 있어야 합니다.
- 스크린샷만 보지 않고 구조 메타데이터까지 함께 읽어야 합니다.
- 컴포넌트 후보는 단순 시각 유사성이 아니라 책임 범위 기준으로 분해해야 합니다.
- `Next.js 16 App Router`와 현재 FSD 친화 구조를 유지해야 합니다.

## 작업 요약

- 우선 전체 프레임 목록을 수집합니다.
- 프레임별로 버튼, 필드, 카드, 섹션 헤더, 리스트 셀, 배지, 아바타, CTA 묶음을 패턴 단위로 분해합니다.
- 반복 횟수와 변형 폭을 기준으로 프리미티브와 위젯을 구분합니다.
- 우선순위가 높은 공통 컴포넌트부터 `shared/ui`에 구현합니다.

## 선행조건

- 유료 Figma seat에 Dev Mode 접근이 포함되어 있어야 합니다.
- 현재 파일에 대한 권한이 있어야 합니다.
- 유효한 Figma 링크 또는 접근 가능한 선택 노드가 필요합니다.
